📸 每日穿搭 + 拍照强度总表

天数 当天场景 拍照强度 建议穿搭 为什么这样搭
D1 · 9/8落地日 飞机 11h + 落地休息 不拍 卫衣/薄针织 + 休闲裤 + 运动鞋 + 防风外套随身 飞机上冷、落地伦敦傍晚可能只有 12°C，外套放手边不托运
D2 · 9/9东区+歌剧魅影 白天贝果+涂鸦街 · 晚 BBR 晚餐+剧院 📸 晚上拍 白天：针织+牛仔裤+运动鞋 · 晚上回酒店换：丝质衬衫或小礼服裙 + 小跟鞋/短靴 BBR 和剧院是 smart casual 场合，吊灯+餐厅都出片；15:30 回酒店本来就安排了换装时间
D3 · 9/10西区+Circolo Covent Garden + Seven Dials + 酒墙晚餐 📸📸 重点 奶油白/浅驼色系：连衣裙或丝质上衣+半裙 + 风衣 + 短靴 Circolo 酒墙是暖黄光深色背景，穿浅色人才跳得出来；白天街区也好拍
D4 · 9/11比斯特购物 全天奥莱暴走+试衣 不拍 针织 + 阔腿裤 + 最好走的运动鞋 + 薄外套 核心是试衣穿脱方便：别穿连体裤、别穿系带多的鞋；大包寄存或放车上
D5 · 9/12市集+Magic Mike 白天彩色房子 · 晚 Magic Mike 📸📸 重点 白天：纯色（白/奶油/黑）+ 风衣，跟彩色房子撞色 · 晚上：辣一点的裙子（House of CB 风格正合适） 彩色房子背景杂，穿纯色最出片；Magic Mike 氛围适合 dress up，现场大家都穿得很嗨
D6 · 9/13花市+进村 Columbia Road 花市 + 蜂蜜色石头村 📸 拍 大地色系：米色/燕麦色针织 + 风衣 + 牛仔裤 + 短靴 花市和蜂蜜色石头都是暖调，大地色系融为一体很温柔；晚上进村凉，风衣必备
D7 · 9/14乡村全天 Bourton / Bibury / Castle Combe 村庄 📸📸 重点 田园感：针织裙或衬衫裙 + 风衣/呢外套 + 短靴（别穿高跟鞋） + 可带贝雷帽 村里全是石板路和草地，鞋比衣服重要；清晨薄雾+傍晚金光是最出片时段
D8 · 9/15回伦敦+Liberty 车程 2.5h + Liberty 百货 + 唐人街 📸 轻 舒服的 smart casual：针织+直筒裤+乐福鞋/运动鞋 上午坐车要舒服，下午逛 Liberty 别穿太运动，一套兼顾
D9 · 9/16V&A+大本钟 博物馆 + Marylebone + 大本钟黄昏 + Soho 夜逛 📸📸📸 最重点 英伦感：风衣 + 丝巾 + 衬衫/薄针织 + 半裙或直筒裤 + 短靴 大本钟黄昏是全程最经典机位，风衣+丝巾就是"伦敦感"本身；博物馆室内暖，里面穿薄点
D10 · 9/17Harrods+House of CB+晚场 Cabaret 百货购物 + 试穿裙子 + 晚上看秀 📸 轻 白天好穿脱的一套 + 运动鞋；内衣穿浅色无痕款；晚上看秀：可用今天在 House of CB 新买的裙子 + 带件外套（剧场空调冷） House of CB 试紧身裙，内衣不对试不出效果；新买的裙子晚上直接穿去 Kit Kat Club 看 Cabaret，刚好首秀
D11 · 9/18回程日 观光巴士 + 按摩 + 红眼航班 📸 巴士上随手拍 坐飞机套装：卫衣+休闲裤+运动鞋，厚外套随身 20:20 飞 11 小时，舒服压倒一切；巴士二层风大，外套别收进行李箱
